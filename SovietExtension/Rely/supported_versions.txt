# SovietExtension supported WeChat versions
# SovietExtension 支持的 Mac WeChat 版本列表
#
# Format / 格式：
# DisplayVersion|CFBundleShortVersionString|CFBundleVersion|Note|ResourcesFatSHA256|Arm64UUID
#
# 字段说明：
# 1. DisplayVersion:
#    你对外展示的精确微信版本，例如 4.1.9.58
#
# 2. CFBundleShortVersionString:
#    WeChat.app/Contents/Info.plist 里的 CFBundleShortVersionString
#    例如 4.1.9
#
# 3. CFBundleVersion:
#    WeChat.app/Contents/Info.plist 里的 CFBundleVersion
#    例如 268602
#
# 4. Note:
#    备注
#
# 5. ResourcesFatSHA256 (optional / 可选):
#    WeChat.app/Contents/Resources/wechat.dylib 的完整 fat SHA-256
#
# 6. Arm64UUID (optional / 可选):
#    上述 wechat.dylib 的 arm64 Mach-O UUID
#
# 同时填写第 5、6 项后，安装器会在修改 App 前强制精确匹配；--force 不会绕过。
#
# Example / 示例：
# 4.1.9.58|4.1.9|268602|Tested
#
# Wildcard / 通配符：
# 4.1.9.x|4.1.9|*|Allow all 4.1.9 builds
# *|*|*|Allow all versions, not recommended
